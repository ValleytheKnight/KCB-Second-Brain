# What This Folder Is

This is **not** a separate project from [[04-projects/knight-code/PROJECT-OVERVIEW|Knight Code]]. It's the auto-synced, human-readable mirror of the actual Knight Code repo (`C:\Users\Chris Brown\Documents\Knight Code`), written here live by that repo's own tooling.

- `memory-export/`: decisions, promises, learnings, and dev-diary entries synced straight from Knight Code's memory system.
- `structure-overview/`: generated overviews of Knight Code's skills, agents, MCP servers, and hooks.
- `Dependency Update Backlog.md`, `KBV2 Design.md`, `Mnemosyne Memory Integration.md`: standalone design/planning notes that live here rather than under `knight-code/planning/`, kept as-is to avoid breaking the sync hook's existing write paths.

**Where to track things by hand:** use [[04-projects/knight-code/PROJECT-OVERVIEW|knight-code/PROJECT-OVERVIEW.md]] and its `braindumps/`, `planning/`, `resources/` subfolders for anything you're manually tracking. Leave this folder to the sync tooling; editing its contents by hand risks it being overwritten or drifting from what the source repo actually contains.
