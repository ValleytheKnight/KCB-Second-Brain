# omarchy-image-theme: canvas audit against 2 v2-deferred items

Chris asked devknight to check whether any mockup visually claims or implies the 2 items just deferred to v2 (decisions d4a2e914, 671c335f). Scanned the text content of every node on all 11 frames rather than spot-checking.  Preview.png generation: nothing to fix. The Selection screen's mini-terminal cards only ever reference applying a theme, never generating or writing a preview image back into Omarchy's own theme folder.  Extra-file preservation: real gap found and fixed. 5 of the Selection screen's 6 theme cards are real official Omarchy themes, each confirmed earlier this session by direct file reads to carry several files beyond colors.toml (an icon theme reference, a keyboard color value, an editor colorscheme, a VS Code theme descriptor, lock-screen and picker preview images).
