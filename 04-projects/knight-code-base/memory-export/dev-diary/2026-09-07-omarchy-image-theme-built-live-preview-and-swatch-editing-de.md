# omarchy-image-theme: built live-preview and swatch-editing detail mockups

Chris still couldn't clearly evaluate two things on the Pencil canvas: the "fake render" live-preview mechanism (buried as a small element on busy screens) and the actual color-editing interaction (never mocked, only referred to abstractly).  Built two new dedicated close-up detail frames on the same live canvas (Pen Designs/omarchy-image-app.pen), working in parallel with a second devknight agent who owned Top Nav / Startup Missing Dependency / v2-labeling. Chose the dedicated-frame approach over increasing prominence on existing screens specifically to avoid any edit collision with that parallel work, since neither new frame touches a screen the other agent owns.  Frame 1, "Detail - Live Preview Mechanism" (m8wVD): side-by-side comparison of the mechanism at both scales it already exists at on canvas, the 84px card-scale version (real copy of the Selection screen's theme card, fj2UF) and the full terminal+wallpaper version (real copy of the Happy Path screen's Preview Row, d0zmXL), plus a LIVE badge and a note explaining both are driven by the same palette with no screenshot taken.  Frame 2, "Detail - Color Swatch Editing" (g9aR2): a real screen state showing one palette swatch (a copy of a real 18-swatch palette swatch, iqMph) in an active/editing state, with a popover below it containing a saturation/value color field, a hue slider, and an editable hex input row with a blinking-cursor look and an eyedropper icon. Chose hex input + native swatch/picker popover as the v1 interaction pattern: the standard low-effort web pattern, genuinely easy to build in a Tauri WebView. Eyedropper included as a near-free addition via the browser EyeDropper API, not counted as required v1 scope. Reasoning is also written directly onto the canvas as an annotation note, not just reported back.  Both frames built entirely from copies of real, already-approved canvas elements (theme card, preview row, real palette swatches) rather than inventing new visual language, and stay within the locked visual direction (dark background, JetBrains Mono headings, Inter body, #F5A153 amber accent) using the document's existing variables throughout.
