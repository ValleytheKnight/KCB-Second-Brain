# Ported 7 engineering-practice skills from addyosmani/agent-skills

Brought 7 of the 24 skills in github.com/addyosmani/agent-skills into Knight Code as knightcode-prefixed skills: incremental-implementation, interview-me, test-driven-development, doubt-driven-development, api-and-interface-design, observability-and-instrumentation, performance-optimization.  Why these 7 and not the rest: the other 17 duplicate capability Knight Code already has under its own names. browser-testing-with-devtools maps to browse/qa, code-review-and-quality to review, code-simplification to the simplify skill, context-engineering to context-save/context-restore, debugging-and-error-recovery to investigate, documentation-and-adrs to document-generate plus decision_log, frontend-ui-engineering to frontend-design, git-workflow-and-versioning plus ci-cd-and-automation plus shipping-and-launch to ship, idea-refine to office-hours, planning-and-task-breakdown to plan-eng-review, security-and-hardening to cso, spec-driven-development to spec, using-agent-skills to writing-skills. Porting them would have created a second way to do the same job, which the Priority Directive exists to prevent.  Port shape followed the emilkowalski port exactly: each skill is a tracked <name>/SKILL.md.tmpl at the repo root carrying the {{PREAMBLE}} placeholder, the installed SKILL.md is generated by bun run gen:skill-docs rather than hand-written, and the runnable copy is installed to the global ~/.claude/skills/knightcode-<name>/ per the current convention. Preamble tiers: tier 2 for the four that run a real work loop and may need to ask something (incremental-implementation, interview-me, test-driven-development, doubt-driven-development), tier 1 for the three that are reference knowledge (api-and-interface-design, observability-and-instrumentation, performance-optimization).  Real adaptation work, not a copy-paste: the source skills cross-reference sibling skills that do not exist here, so every pointer was retargeted to Knight Code's own equivalents (investigate, ship, cso, spec, office-hours, plan-eng-review, review, browse, health) or folded inline where nothing matched, and dangling references/*.md pointers were removed. The doubt-driven skill's persona/orchestration constraints were rewritten against this repo's real agent rules (agents exist only via create_agent/update_agent, list_agents is ground truth over AGENTS.md), and its cross-model escalation was made tool-agnostic since naming a specific external CLI would have pointed at a plugin whose name is project-isolation banned. interview-me was rewritten to Chris by name and wired to question_search so a recurring-shaped question folds in prior answers. performance-optimization's revert ledger now points at learnings_log as its durable home.  Hygiene: every em dash removed, plus the banned words the source carried (landscape, significant, robust, notably). The write-time hygiene gate caught one on first attempt (landscape, in an image-crop comment), which is the gate working as designed. Post-port scan of all 7 templates against scripts/banned-language.json came back clean.  Verified rather than assumed: gen:skill-docs regenerated all 39 templates with no unintended drift elsewhere, skill:check reports all 7 templates paired with fresh generated output, installed copies byte-match the repo copies, and all 7 now appear in Claude Code's own live skill list, which only happens if the frontmatter parsed. Wired into CLAUDE.md's general routing table rather than devknight, on the same reasoning as the emilkowalski port: the discipline is platform-agnostic even though the code samples are TypeScript/React/REST. Skill counts in CLAUDE.md and TODOS.md moved from 30 to 37.
