# Scryptable logo concept, six drafts to an approved temp direction

Full iteration history in whisper_app_design.pen's "Logo Concepts" frame (M3a8n), all built via Generate(type:"svg"), never hand-assembled paths, all prior directions left on canvas untouched:  1. Quill + separate audio-waveform element behind the feather. Rejected: waveform wasn't part of the feather. 2. Feather barbs reshaped as literal waveform bars. Rejected: read as an abstract dark bar-burst, not a quill, worse than draft 1. 3. Quill + headphones wrapped around it, waveform dropped entirely. Chris hated this direction outright, discarded. 4. Reference image supplied (teal/blue quill, white heartbeat line through the feather, paper+signature, rounded-square background), recolored to brand orange, waveform line running through the feather at its own angle, paper+signature kept. Chris: closer, but line needs to follow the feather's angle and drop the paper. 5. Revised in place: waveform following feather tilt, paper dropped. Chris: still wrong, "follow the angle" was too vague; gave a precise spec off the reference (layered lobes with tonal shading, waveform along the feather's central spine/rachis axis, peaks perpendicular to that axis). Built as a new slot, Logo E. Chris: worst attempt yet, killed the whole waveform-embedded-in-feather direction entirely. 6. New concept: plain, undecorated feather in flat brand orange, the waveform is the ink trail extending from the nib's exact tip, as if the pen is actively drawing it, no paper. First pass had the waveform starting slightly off from the nib; revised so the line originates exactly at the nib's point. Chris approved this as the temp/working logo.  Color-precision note: the AI SVG generation's own color interpretation of "#FF8400" came out approximate every round it was checked (#E8711C, then #EC6020), never the exact hex. Verified the real locked value directly from src/scryptable/theme.py's PRIMARY constant ("#FF8400") rather than trusting the design record's prose description, and corrected the approved draft's path fill with a direct Update call once generation finished, since Generate's own color fidelity isn't reliable for exact brand hex matching.  Current status: approved as Chris's temp/working logo, marked as such on the canvas (frame renamed, "APPROVED (temp)" label added). Not yet backed by a logged decision; Chris said he will log that himself from the primary session. Per the standing rule, stays out of real app code until that decision exists.
