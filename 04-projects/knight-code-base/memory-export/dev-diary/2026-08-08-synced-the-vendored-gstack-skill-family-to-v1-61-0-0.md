# Synced the vendored gstack skill family to v1.61.0.0

The "(knightbrain)"-tagged skills under ~/.claude/skills/ (canary, guard, benchmark, codex, land-and-deploy, etc.) turned out to be a locally rebranded vendor copy of garrytan/gstack, installed flat (no .git, no gstack/ wrapper folder), so gstack's own upgrade skill couldn't run its automated git-based flow. Its hardcoded vendored-install clone URL also pointed at a dead repo (a placeholder author, not gstack's real one) that 404s.  Manually replicated what the vendored-install path would have done: shallow-cloned the verified real repo (github.com/garrytan/gstack, confirmed live via GitHub API), applied the same case-sensitive gstack->knightbrain / GSTACK->KNIGHTBRAIN text transform already present throughout the existing local files, and wrote the result back into each of the 21 present local skill directories (5 skills referenced in the skill listing, the ios-* family, don't actually exist under ~/.claude/skills/ at all and were skipped).  19 of 21 had real content drift and were updated; guard and the root command skill were already current. Also caught and fixed along the way: a live bug in the vendored-install clone command (fake author placeholder instead of the real repo), a missing migrations/ directory (10 scripts) and dx-hall-of-fame.md that were never vendored in the first place, and one casing miss (mixed-case "GStack" survived the lowercase/uppercase-only transform in several files, most visibly in the browser skill's own description).  Left untouched, flagged for a human call: a "GStack voice: Garry-shaped product judgment" persona line duplicated across most of these skills, and illustrative example data in retro/SKILL.md's sample output referencing Garry Tan by name. Both are content/persona decisions, not mechanical rebrand fixes.  Pre-update copies of every touched file live at ~/.knightbrain/pre-update-backup-2026-08-08/.
