# browse's screenshot command needs a sharp/detect-libc reinstall, raw CDP capture works as a bypass

While getting real screenshots of KnightOS's Project Tabs Task A mockup into the vault, `browse screenshot` failed with "Cannot find package 'detect-libc' imported from .../node_modules/sharp/dist/sharp.mjs" on first use this session, before any change was made. Attempted two blind version fixes in `C:\Users\Chris Brown\.claude\skills\knight-code` (`npm install detect-libc@2 --no-save`, then `npm install sharp --no-save`, then `npm install detect-libc@1 --no-save`), none restored the screenshot command; each `npm install` call in this directory removes and re-adds packages (there is no `package.json` here, only a nearly-empty `package-lock.json`, so npm has nothing to constrain the install against, meaning any bare `npm install <pkg>` in this directory is liable to shuffle unrelated packages around). Current end state: `detect-libc@1` is installed, and `browse screenshot`/`prettyscreenshot`/`responsive` (anything routed through sharp for image post-processing) still fails with `ENOENT ... sharp/dist/index.mjs`, a genuinely different error than the one this session started with, so the dependency tree is left in a different, still-broken state, not restored to how it was found.  Real, verified workaround that does not depend on sharp at all: `browse cdp Page.captureScreenshot '{"format":"png"}'` returns a base64 PNG directly from Chrome DevTools Protocol, wrapped in the tool's normal untrusted-content envelope. Decode the `data` field's base64 and write it to a `.png` file directly; this bypasses whatever post-processing step sharp is supposed to provide (likely resizing/cropping for `--selector`/`--clip`, not needed for a plain full-viewport capture). Used successfully to capture KnightOS's Task A mockup this session.  This needs a real, deliberate fix by whoever maintains this skill's vendored `node_modules` (matching the exact sharp/detect-libc version pair the prebuilt bundle expects, then pinning it), not another blind version guess.
