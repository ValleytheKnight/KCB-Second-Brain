# Scryptable Task 9: Transcript Assembly built and verified

Task 9 (Transcript Assembly) is complete. Real source found and ported: a working TASMAS checkout at /home/vtk/Documents/D&D/Felled God/Discord Episode Recording/_tasmas/ (tasmas.py, assemble.py, configuration.py), the same situation Task 6 was in with transcribe_stems.py. New module src/scryptable/assembly.py ports the real core merge algorithm: sort every word by real timestamp, group into per-speaker sentences at punctuation, collapse adjacent same-speaker sentences, flag a sentence whose start lands well before the running clock as out of sync, write transcript.txt (and outOfSyncItems.txt when anything is flagged).  Handles both speaker sources in this codebase: multi-track/Craig stems (one file per speaker, resolved through Task 8's speaker_identities) and a diarized single mixed file (one file, per-word "speaker" field from whisperx's assign_word_speakers, no name resolution UI for this path since Task 8 explicitly never covers it either).  The Design Review's four named settings all wired to real behavior: out-of-sync flag threshold (configurable, was hardcoded 5s), include-timestamps toggle, corrections file source (new src/scryptable/corrections_master.py, workspace-wide corrections-master.json, minimal load-only shape mirroring names_master.py, matching the real shape Task 10 will build the full editor on top of), and the resolved "speaker name format" setting (decision 6f68ac6e, a column-alignment toggle exposing the real TASMAS rjust-padding behavior, default on).  New AssemblySettingsDialog (Recording menu, "Transcript Assembly Settings...") and AssemblyWorker (background QThread, matching transcription/diarization's own worker shape) wired into RecordingTab (a new Assemble Transcript button, enabled once assembly.is_ready() says so) and MainWindow. No UI label anywhere names TASMAS, verified by two automated regression tests scanning the real menu bar and the real button text.  Full build history and every real finding: Projects/Scryptable/06 Lessons Learned/Task 9 Transcript Assembly Build Notes.md in the DevKnight Workshop vault.
