# Decision: Scryptable's product name is "StemScrypt."

## Decision

Scryptable's product name is "StemScrypt."

## Rationale

Chris's own pick after two rounds of name brainstorming; the first round's picks (Session Ledger, etc.) were rejected for sounding like existing products, and the follow-up pick "Transcrypt" collided with an existing open-source Python-to-JS transpiler of the same name. WebSearch for "StemScrypt" found no existing product, company, or tool using it, closest unrelated hits were a credential-verification company, a bioinformatics tool, and a stem-cell biotech firm. "Working title" internally has been "Scryptable" up to this point; that name now retires in favor of StemScrypt for all future docs, screens, and code.
