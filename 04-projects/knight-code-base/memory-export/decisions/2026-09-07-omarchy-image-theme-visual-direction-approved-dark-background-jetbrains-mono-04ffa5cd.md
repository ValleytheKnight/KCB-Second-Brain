## Decision

omarchy-image-theme visual direction approved: dark background, JetBrains Mono for headings/labels/nav, Inter for body text, warm amber (#F5A153) accent, terminal-flavored live preview panel

## Rationale

Echoes Omarchy's own existing dark, minimal, terminal-forward identity rather than a generic light/neutral SaaS look, since this app is a companion tool for Omarchy's own users. Chris confirmed after reviewing 7 mockup screens live in Pencil (Pen Designs/omarchy-image-app.pen in the Knight Code repo): Generate-from-photo empty/loading/success/error, and Edit-existing-theme selection/loaded/error.
