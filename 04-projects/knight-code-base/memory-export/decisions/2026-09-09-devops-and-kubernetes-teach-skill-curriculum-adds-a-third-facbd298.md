# Decision: DevOps and Kubernetes teach-skill curriculum adds a third standing rule: Concepts before tools. Ever...

## Decision

DevOps and Kubernetes teach-skill curriculum adds a third standing rule: Concepts before tools. Every lesson teaches the underlying mechanism before/alongside the specific tool, exposure to common tools stays but is the vehicle, not the point.

## Rationale

Chris's instruction: tools change constantly, understanding what a tool is doing and how the pieces work together matters more than fluency in one specific tool. This is a standing audit criterion, not a one-time edit: any future roadmap review must check each phase against it. Alternatives not chosen: leaving tool exposure as the only stated goal per phase (rejected, tool fluency alone goes stale); making this a one-off wording tweak in a single phase instead of a durable cross-cutting rule (rejected, Chris wants it checked against the whole roadmap going forward, same footing as the existing hands-on and continuous-push rules).
