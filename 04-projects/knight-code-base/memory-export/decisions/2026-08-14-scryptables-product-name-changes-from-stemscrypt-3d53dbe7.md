# Decision: Scryptable's product name changes from "StemScrypt" to "Scryptable."

## Decision

Scryptable's product name changes from "StemScrypt" to "Scryptable."

## Rationale

Chris's pick, mid-mockup session. WebSearch found no existing product/company/tool using "Scryptable" exactly, though it sits near "scrypt" (a real cryptographic key-derivation algorithm) and "sCrypt" (a Web3 dev platform), flagged to Chris as an adjacency risk, not a hard collision, he proceeded anyway. This supersedes the "StemScrypt" name decision logged earlier in this same session.
