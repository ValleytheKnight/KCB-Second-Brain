# Decision: KnightOS's roadmap gets a new milestone: a dashboard/analytics overview across all open channels, no...

## Decision

KnightOS's roadmap gets a new milestone: a dashboard/analytics overview across all open channels, not currently part of the Milestone 1-4 sequence. Real scope, to be sequenced and task-broken later, not built now.

## Rationale

During the Milestone 1 design pass, Chris reacted to inspiration images (HOLO HOME, Amazon Ops mock, Claude Code Agent Monitor, ASO workflow board, Portable Agent Supervisor, Glyphic) that are all richer multi-panel dashboards, a different kind of surface than Milestone 1's tabbed shell. After confirming Milestone 1's narrow scope is correct and intentional (per decision dc8e14d6's vertical-slicing rule), Chris stated directly that a dashboard/analytics capability needs to be built into the plan, not just left as a mockup exercise. This is a genuine new roadmap item, not a redefinition of Milestone 1.

## Alternatives Considered

Treating the north-star mockup as pure inspiration with no real roadmap entry (rejected, Chris explicitly said this needs to be in the plan, not just a vision exercise). Folding dashboard/analytics into an existing milestone like the graph panel milestone (rejected for now, no evidence yet that they belong in the same milestone, this needs its own sequencing decision later, not a default merge).
