## Decision

KnightOS multi-window system (browser/markdown/diff/file-explorer windows, tabbed/stacked/split layout modes, tear-off to real OS windows), multi-workspace sidebar, and the full new interaction layer (command palette, global search, MCP OAuth-style auth flow, onboarding flow, context menus) are confirmed as real, wanted scope from knightos-mockup.pen, none of it is exploratory or aspirational.

## Rationale

None of this had a prior milestone; the mockup adds it wholesale. Chris confirmed all of it as genuinely wanted rather than picking pieces, clearing the way for eng review to size it without second-guessing whether it's really in scope. Alternative considered: partial scope, picking pieces to build now vs later, rejected, Chris confirmed all of it as wanted.
