# Learning: technical-thread-reply-scope

## Insight

For a terse technical GitHub thread reply, the useful pass is de-AI mechanics only (em dash, pronoun swap, banned vocab check) — full conversion-copy voice work (rule-of-three, concrete-over-abstract, CTA framing) doesn't apply and would distort a factual security-review reply.
