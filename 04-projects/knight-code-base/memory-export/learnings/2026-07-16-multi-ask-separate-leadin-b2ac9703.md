# Learning: multi-ask-separate-leadin

## Insight

When a document makes two asks under two different authorities, tacking the second onto the first ask's closing sentence blurs them for the reader -- giving the second ask its own clearly separated lead-in ("Separately, on X:") reads cleaner. Generalizes beyond marketing copy to any multi-ask document.
