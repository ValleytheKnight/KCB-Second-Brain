# Learning: stale-factual-claim-drift

## Insight

A README's own factual claims about behavior can drift stale after the underlying product changes. Copyedit passes should flag factual/behavioral claims for verification against the current implementation, not just polish their prose -- a well-written sentence describing wrong behavior is worse than an awkward one describing right behavior.
