# Learning: repeated-if-you-opener

## Insight

In a multi-section technical README, three separate feature sections each opened with "If you..." -- a repeated-construction tell distinct from em-dash/word-level tells. Converting at least one into a question hook ("Already have X? ...") broke the monotony without changing the technical claim. Check sentence-openers across sections, not just within one, on any doc with repeated subsections.
