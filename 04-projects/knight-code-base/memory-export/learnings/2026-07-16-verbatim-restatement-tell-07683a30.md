# Learning: verbatim-restatement-tell

## Insight

Restating the same fact verbatim in two sections of a short document is a subtler AI-prose tell than em-dashes/hedge words. Swapping the second instance for a backward reference ("that time" instead of restating the number) reads more human and signals the sections are one coherent piece, not independently generated blocks.
