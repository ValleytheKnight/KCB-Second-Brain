# Learning: code-block-scoped-rule0

## Insight

A technical README with code blocks needs the same Rule 0 pass as prose-only docs, but scoped: edits land only in the surrounding paragraphs while every code block, selector, file path, and any documented policy trade-off stay untouched, unless explicitly told to soften a documented limitation. Confirms the table-preservation candidate generalizes to code blocks too.
