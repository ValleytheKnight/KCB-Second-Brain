# Learning: hygiene-gate-blocks-dated-narrative-headings-in-docs

## Insight

The Knight Code hygiene gate blocks non-code markdown writes too, not just code comments: a heading like "## Addendum (added 2026-07-28, same session)" tripped the dev-diary date/narrative pattern even in a CEO-plan doc under ~/.knightcode/, outside the tracked repo. Required fields like "Generated by /plan-ceo-review on {date}" in the skill's own template survive; ad hoc "(added {date}, ...)" narrative framing does not. Fix: state facts plainly without a narrative "added on X" wrapper.
