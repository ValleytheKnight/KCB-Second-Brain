# Learning: comma-spliced-however

## Insight

A comma-spliced "however" (", however," joining two independent clauses with commas only) reads as an AI-prose grammar tell distinct from em-dash overuse -- splitting into two sentences and using "however" as a proper mid-sentence interrupter fixes it without dropping the requested word choice.
