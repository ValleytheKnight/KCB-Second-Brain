# Learning: cut20-carveout-reference-tables

## Insight

The "write it, then cut 20%" rule needs a carve-out for reference material: a settings/frontmatter table inside an otherwise-prose README should not be cut for brevity, only the prose framing around it. Treat "shorter than the original" as applying to the prose word count, not the total document, when technical accuracy content is present.
