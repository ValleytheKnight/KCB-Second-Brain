# Learning: char-limit-measure-programmatically

## Insight

For a hard character-limit deliverable, measure each draft's exact length programmatically before presenting it, rather than eyeballing or counting by hand -- caught that an initial draft was comfortably under budget and left room to add one more concrete feature instead of trimming later.
