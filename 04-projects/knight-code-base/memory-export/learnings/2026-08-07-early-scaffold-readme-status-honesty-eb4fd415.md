# Learning: early-scaffold-readme-status-honesty

## Insight

An early-scaffold plugin README (no working build yet) needs the same Rule 0 tightening pass as a finished README, but the "Status" section's honesty claims (no working build, an open technical question still unresolved) must survive the edit verbatim in substance -- only the phrasing tightens, not what's admitted. Confirms the stale-factual-claim-drift pitfall generalizes to under-claiming too, not just over-claiming.
