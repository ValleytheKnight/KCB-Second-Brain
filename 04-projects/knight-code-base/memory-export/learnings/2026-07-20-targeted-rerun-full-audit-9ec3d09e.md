# Learning: targeted-rerun-full-audit

## Insight

A targeted re-run on a small, freshly-edited section of an already-polished README still benefits from the same full audit as a first draft. Do not skip Rule 0 on "just a small patch" edits just because the surrounding document already passed a prior pass.
