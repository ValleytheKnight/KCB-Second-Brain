# Learning: listing-vs-readme-register

## Insight

A store/marketplace listing description is a different audience than a technical README even from the same feature list: a first draft that included implementation syntax read like documentation, not sales copy. Cutting to the feature/outcome level and dropping how-to-invoke-it syntax made it read as marketing instead of instructions.
